# Let’s 狗 · 手作宠物小食

根据提供的小程序首页参考图制作的移动端网页。使用原生 HTML、CSS、JavaScript、Node.js，无需安装项目依赖。

## 启动

需要 Node.js 18 或以上。在仓库目录执行：

```sh
npm start
```

默认端口 3000，可用 `PORT` 环境变量覆盖。服务监听 `0.0.0.0`。

## 交互

- 首页三种履约方式进入点单；商品分类、添加购物袋、增减数量和金额计算。
- 结算表单验证联系人、11位手机号；外卖、快递还需要收货地址。
- 创建本地演示订单，查看订单列表和详情。
- 会员演示充值、余额显示；门店信息、喂食说明弹窗。
- 购物袋、订单、履约方式和余额使用 localStorage 保存。

这是网页实现，不是微信原生小程序。商品和门店为演示数据。充值不产生扣款，订单不触发真实支付和配送；上线业务需要接入后台、微信登录、支付和履约服务。请勿输入真实个人信息。

手绘 SVG 为参考图风格重绘，不是原图素材，无法保证像素级相同。本地 Ma Shan Zheng 字体许可见 `public/fonts/LICENSE`。

## 验证

`npm test` 检查 JavaScript 语法。开发时另使用 Playwright 和系统 Chromium 验证了履约方式、购物袋、结算、订单持久化、充值以及 375px 手机宽度无横向溢出，未发现浏览器运行错误。
